# Работа с ASCII Studio

## Настройки

| Настройка | Что меняет |
| --- | --- |
| Детализация: 40–280 колонок | Меньше колонок — крупнее символы. Больше — тоньше детали. Есть три быстрых пресета. |
| Набор символов | Классический, расширенный, минимализм или `01`. |
| Палитра | Золото, белый, зелёная «Матрица», исходные цвета или произвольный цвет. |
| Цвет фона | По умолчанию настоящий чёрный `#000000`. |
| Контраст, яркость, контуры | Помогают проявить объект и сохранить читаемость. Настройки ниже палитры доступны прокруткой панели. |
| Инверсия | Меняет соответствие яркости и плотности символов. |
| Размер экспорта | Авто (до 4K), 720p, 1080p, 1440p / QHD и 2160p / 4K UHD. |
| Частота кадров | Авто, 24, 25, 30, 48, 50, 60, 90, 120, 144, 165, 180, 200 или 240 fps. |
| Увеличивать до выбранного размера | Перерисовывает ASCII-символы в выбранном разрешении, даже если исходник меньше. Например, HD → 4K. По умолчанию выключено. |
| Интерполяция при экспорте | Вычисляет промежуточные кадры, если выбранный FPS выше исходного. По умолчанию выключена. |
| Исходный звук | Включает первую аудиодорожку в результат; при необходимости дополняет короткий звук тишиной. |

Экспорт: **MP4 / H.264 / AAC**. Вертикальная ориентация сохраняется. Видео с переменной частотой кадров приводится к постоянной частоте по временным меткам.

4K UHD ограничивает кадр размерами **3840 × 2160**, для вертикального видео — **2160 × 3840**. Пропорции сохраняются. Меньшие исходники увеличиваются только с включённым флажком; режим разрешения «Авто» никогда их не увеличивает. Символы отрисовываются на большом холсте заново, без растягивания готовой ASCII-картинки. Детали снятой сцены при этом не восстанавливаются. Под настройками указаны фактические размер и FPS результата.

Автоматический FPS сохраняет частоту исходника в пределах 240. При повышении FPS можно выбрать повторение кадров либо **интерполяцию движения**. Интерполяция использует FFmpeg `minterpolate` с оценкой движения исходных изображений до ASCII-преобразования. Для скорости движение рассчитывается на кадрах до 1280 × 720 (либо 720 × 1280), а символы выводятся в полном выбранном разрешении. Детектор смены сцен переключается на повторение кадров на резких склейках. На сложных движениях возможны искажения; интерполяция существенно замедляет экспорт. Нейросети и дополнительная загрузка моделей не нужны.

**Предпросмотр показывает исходное движение.** Интерполяция применяется при экспорте; её флажок становится доступным после выбора FPS выше исходного. Рабочий кадр для расчёта движения должен быть не меньше 32 пикселей по каждой стороне.

## Автонастройка изображения

Кнопка **Авто** вверху панели стиля анализирует 6–18 кадров из разных частей ролика и подбирает только контраст, яркость и силу контуров. Палитра, детализация и набор символов сохраняются. Алгоритм исключает пустые чёрные/белые кадры, обрезает чёрные поля для анализа и ограничивает усиление контуров при шуме.

Результат фиксируется для всего ролика, поэтому параметры не скачут от кадра к кадру. **Вернуть настройки до «Авто»** отменяет последний подбор, а ползунки позволяют поправить результат вручную. Анализ можно отменить повторным нажатием кнопки. «Авто» даёт отправную точку, а не гарантирует одинаково удачный художественный результат для любой сцены.

**Предпросмотр работает без звука**, с ограниченным разрешением для скорости. Он может пропускать кадры на слабом компьютере; экспорт обрабатывает все кадры выбранной частоты. Рендер выполняется на CPU, поэтому длинные ролики, интерполяция и большие разрешения требуют больше времени. По умолчанию экспортируется весь ролик.

Экспорт можно отменить. Промежуточный файл удаляется, а уже существующий результат заменяется только после успешного завершения. Приложение не позволяет экспортировать поверх исходника.

## Управление

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O` | Открыть видео |
| `Ctrl+E` | Экспорт |
| `Пробел` | Воспроизведение / пауза |
| `←` / `→` | Назад / вперёд на 5 секунд |
